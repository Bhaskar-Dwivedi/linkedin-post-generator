# 🚀 AI LinkedIn Post Generator

An AI-powered web application that generates professional LinkedIn posts using Large Language Models.  
Users can enter a topic, choose their preferred style, and instantly generate engaging LinkedIn content.

## ✨ Features

- 🤖 AI-powered LinkedIn post generation
- ✍️ Creates professional and engaging content
- 🎯 Generates posts based on user topics
- #️⃣ Suggests relevant hashtags
- ⚡ Fast response using Groq API
- 🌐 Flask backend API
- 🔒 Secure API key handling with environment variables

## 🛠️ Tech Stack

### Backend
- Python
- Flask
- Flask-CORS

### AI
- Groq LLM API

### Other Tools
- python-dotenv
- httpx
- Gunicorn

## 📸 How It Works

1. Enter your LinkedIn post topic
2. AI analyzes the topic
3. Generates a professional LinkedIn post
4. Copy and share it on LinkedIn
